# blog

hi people. this is barnacl437's personal website called pacific void centre. made with eleventy. thank god.

forked repository. feel free to read my articles (if any). i write about stuff.

heavily underway.

originally a companion code to the “6 Minutes to Build a Blog from Scratch” tutorial: https://www.youtube.com/watch?v=kzf9A9tkkl4. i suggest you take a look if you want to build your own website using 11ty.


curious what does it feel like? run these two commands:

```
npm install
npm start
```

Navigate to `http://localhost:8080/` in your web browser.
